2. Performance Analytics Engine & 5-Pillar Ingestion

The Performance Analytics Engine synthesizes 5 distinct data streams into a holistic student proficiency profile:

💡 1. 3D Chapter Experience

Tracks scene journey completion & 3D mesh spatial exploration time.

📚 2. Videos Watched (%)

Tracks video watch completion rate & rewind heatmaps.

🧪 3. Experiment Gameplay

Measures virtual lab scores in Shadow Lab & Laser Bounce.

🔷 4. Platform Quizzes (50%)

Deep concept diagnostic metadata driving 3D remediations.

🔶 5. Teacher Tests (50%)

Ingests macro result marks directly into official gradebook.

Academic Score Formula (50/50 Rule):
Academic Score = 0.50 × (Platform Quiz Score) + 0.50 × (Teacher Test Score)

Practical Effort Score Formula:
Practical Score = 0.40 × (Lab Gameplay Score) + 0.35 × (3D Sim Completion %) + 0.25 × (Video Watch %)

Master Composite Score:
Composite Learning Index = 0.70 × (Academic Score) + 0.30 × (Practical Score)

4. Hybrid Storage Model (Supabase DB + Cloudflare R2 $0 Egress)

By pairing Supabase PostgreSQL for relational tables with Cloudflare R2 for heavy binary assets, egress bandwidth fees are reduced by over 98%!

Asset Type Storage Location Cost & Performance Benefit
User Profiles, Auth, Scores, Telemetry 🛡️ Supabase PostgreSQL ACID compliance, RLS security, real-time channels
3D GLTF/GLB Scene Models (20MB-150MB) 🚀 Cloudflare R2 CDN $0 egress fees, sub-50ms instant loading edge caching
HD Video Stories & Audio Lessons 🚀 Cloudflare R2 CDN High-bandwidth media streaming with zero data transfer cost
Lab Worksheets & PDF Documents 🚀 Cloudflare R2 CDN Global CDN edge caching for fast document delivery
