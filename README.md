## 🚀 Key Features

1. **Aria AI Tutor:** Multimodal Socratic tutor powered by Google Gemini with screen vision inspection and continuous voice loop.
2. **3D Virtual Simulations & STEM Labs:** Optics, shadow labs, circuit building, skeletal systems, and solar systems rendered in Three.js.
3. **Multi-Tenant Portals:** Complete role-based suites for Students, Teachers, School Administrators, and SuperAdmins.
4. **Zero-Waste Engineering:** Clean, modular Vite + React architecture with static bundling and automated GitHub Pages deployment.
